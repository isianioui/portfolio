# Personal Portfolio Website

A modern, responsive portfolio website built with TypeScript, React, and a custom UI component system.

## Features

- **Modern UI Components**: Built with a custom component library including buttons, badges, sheets, and more
- **Toast Notifications**: Integrated toast notification system for user feedback
- **Command Interface**: Keyboard-accessible command palette for navigation
- **Responsive Design**: Fully responsive layout that works on all device sizes
- **TypeScript**: Type-safe codebase for better developer experience and fewer bugs

## Tech Stack

- **React**: Frontend library for building user interfaces
- **TypeScript**: Static type checking for JavaScript
- **Shadcn/UI**: Component styling approach (based on the component patterns seen in the codebase)
- **CSS Variants**: Dynamic styling with variant support



### Installation

1. Clone the repository:

```bash
git clone https://github.com/isianioui/portfolio.git
```

2. Navigate to the project directory:

```bash
cd portfolio
```

3. Install dependencies:

```bash
npm install
```

4. Start the development server:

```bash
npm run dev
```

## Project Structure

- `src/components/ui/` - Reusable UI components
- `src/hooks/` - Custom React hooks including toast notifications
- `public/` - Static assets

## Customization

You can customize the portfolio by:

1. Modifying component variants in the UI components
2. Updating content in the main page components
3. Adjusting the toast notification settings in `use-toast.ts`

## Deployment

This portfolio can be deployed to platforms like Vercel, Netlify, or GitHub Pages.

Example deployment command:

```bash
npm run build
```
